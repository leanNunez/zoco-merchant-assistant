# Zoco Cortex: harness de agentes

Segunda prueba técnica de Zoco: un motor pequeño, ejecutable y verificable para agentes con
permisos, memoria, control humano y seguimiento comercial, separado por empresa.

Estado: en construcción en la rama `prueba-2`. Evaluación: `make eval` (13 escenarios del kit más
variantes propias, verificados contra el estado real).

La primera entrega (buscador, agente, máquina de estados y evaluación) sigue intacta: etiqueta
`prueba-1` y [PRUEBA_1.md](PRUEBA_1.md).
